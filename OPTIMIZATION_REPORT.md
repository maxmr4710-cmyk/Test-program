## 🚀 Как использовать

### Для запуска цикла разработки (Roo Code):

```
1. Открой VS Code с расширением Roo Code
2. /mode orchestrator
3. /task Инициализируй проект и запусти полный цикл разработки для десктопного приложения трейдинга
```

Оркестратор автоматически:
- Инициализирует окружение
- Запускает 8 этапов разработки
- Координирует 10 специализированных агентов
- Логирует прогресс в logs/cycle.log

### Для KiloPyth_base (Kilo Code):

```
/kilo startcycle-desktop
```

Использует новый startcycle-desktop.md с 8 этапами и модульностью.
